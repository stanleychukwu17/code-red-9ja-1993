registed voters per polling unit {
  inec report on the 2023 election {
    https://inecnigeria.org/wp-content/uploads/2024/02/2023-GENERAL-ELECTION-REPORT-1.pdf
    - inside this pdf, inec gave their assesment on the state of elections in nigeria for the year 2023
    - you'll find for each state and the total number of registed voters in that state
  }
  ogun: {
    https://inecnigeria.org/wp-content/uploads/2024/11/PU-LEVEL-FOR-PVC-COLLECTED-FOR-2024-ONDO-GOVERVORSHIP-ELECTION.pdf
    use the ogun template to retrieve that of other states
  }
}
